# 変更履歴

## 2026-11-02 v1.1.0

- 画面変更前を v1.0.0 とし、候補検索と不具合表示の分離を v1.1.0 とした。版番号は `APP_VERSION` で管理し、フッター右へ表示する。
- 検索条件の「検索」を、品番行の「候補検索」と日付行の「不具合表示」に分けた。欄と行は増やしていない。
- 候補のワンクリックは選択のみ。「不具合表示」とダブルクリックが、選択中の品番と期間で不具合一覧を出す。
- 品番を選択後に変更すると選択と不具合一覧を消す。候補が複数の候補検索では、品名・客先と不具合一覧を空に戻す。
- 自動Tests 54件は成功。PostgreSQL専用exeを再ビルドし、アーカイブ検査はPASS。exe起動後のDB接続と画面操作は未確認。
